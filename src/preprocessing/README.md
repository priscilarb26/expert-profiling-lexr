# Pré-processamento

Esta pasta reúne os scripts e utilitários responsáveis pela preparação dos dados da base LExR para as etapas de análise, avaliação semântica, prompting e treinamento dos modelos. Os procedimentos podem incluir limpeza, normalização, transformação e organização dos dados de entrada.

Execute os módulos conforme as instruções e parâmetros definidos em cada arquivo, preservando a rastreabilidade entre os dados originais e os conjuntos preparados para os experimentos.
